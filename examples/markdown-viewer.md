# Markdown Viewer

Welcome to the **tuiOS Markdown Viewer**.

## Features

- GitHub-style headings and emphasis
- Ordered and unordered lists
- Fenced code blocks
- Tables and blockquotes

### Code example

```rust
fn main() {
    println!("Rendered by tui-markdown!");
}
```

> Markdown should be readable and useful even inside a terminal UI.

| Feature | Status |
|:--------|:------:|
| Headings | Ready |
| Lists | Ready |
| Tables | Ready |
| Code | Ready |

## Controls

Use **Up** / **Down** or **W** / **S** to scroll. Page Up and Page Down move faster. Press **Q**, **Backspace**, or **Escape** to close.
